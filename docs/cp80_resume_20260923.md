## 보존 및 재사용

중단 전 로그와 stop receipt는 105case 중30case 완료를 기록한다. 재개 helper는 이30개의 manifest와 모든 연결된 배열의 SHA256·shape·dtype, 원본 CT/GT SHA를 확인한다. 검증을 통과한 case만 재사용하며 원본 파일을 복사하거나 덮어쓰지 않는다. 나머지75case는 기존 Basic preparation 함수 본문을 그대로 사용한다. 원래 atomic publication은 이미 있는 배열이 동일한 SHA인 경우만 허용하며 다른 내용은 명시적으로 실패한다. 기존 부분 파일과 pending 파일은 삭제하지 않는다.

`tools/resume_basic_cp80_preparation.py`는 격리된 함수 namespace에서 출력 폴더 검사와 job dispatcher만 교체한다. 원래 모듈 globals와 소스는 변경하지 않는다. 기존 Basic source identity, 전처리 의존성4개, native manifest 해시가 중단 전 receipt와 같지 않으면 시작하지 않는다. 독점 lock과 새로운 attempt별 receipt를 사용한다.
