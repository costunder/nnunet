BEST는 기존 source-anchor 1P+128U patient-macro 검증에서 미리 선택했다. 이번 hard 점수로
checkpoint를 재선택하지 않았다. latest의 cursor epoch는 부분 epoch일 수 있고 완료epoch와 다르다.
native라는 arm 이름은 native-U 학습 정책이며 v2.2 LocalCNN 모델을 뜻하지 않는다.

평가 계약: 기존 v2.2 관측 P/U inventory의 동일21환자, 전체 P135+U2688(환자당128U),
seed42 독립 train-only donor 고정. 이전 V1/A/B/C hard reference와 cohort·donor·후보·GT가 같다.
5개의 zero-P case도 전부 score했다. first-P MRR/Hit@1 분모는16case, micro recall 분모는P135,
P×U 분모는17,280이다. 관측 P는 외부 donor 적합성 정답이 아니며 U도 CP 부적합 정답이 아니다.
4arm 모두 원본10,434,532 parameters, hidden128/4heads/GAT3+2+2층, 48³·5channel·실제2view를
보존했다. L0만 측정 batch로 chunk하고 upper는 환자 전체 후보를 한 번에 처리했다. 규모 축소 없음.

검증 구분: Linux CPU UNIT 21개 PASS는 checkpoint/cache admission 검사다. 실제 CT 전체8개
CUDA inference 완료와 분리한다. 로컬 재집계/비교/이 보고서 생성은 neural forward를 실행하지 않았다.
로컬float64 재집계 metric의 서버값과 비exact 항목은1개, 최대abs차=1.11022302e-16다. rel/abs1e-12 검사와 양쪽값을 JSON에 기록하고 서버값을 유지했다.
원본 upper geometry cache만 재사용했고 model feature/가중치 cache는 없다. 각 모델21회 cache hit,
원본 입력/region/source/prototype/cache SHA의 최종 재확인과 private mmap 결속이 통과했다.
