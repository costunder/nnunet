GPU 1 nnU-Net CP 계약
역사적 BEST GNN을 고정하고 각105 학습 recipient의 모든P+128U를 공동 scoring한다.
128U 전체 점수와 원래 좌표를 유지하고, donor 전체 footprint가 원래 CP 규칙을 만족하는 후보 중 최고 점수를 실제 Copy-Paste한다.
원래 native128U는 distance exclusion 없는 랭킹 비교 위치이므로 모두 CP 가능하다고 가정하지 않는다.
간 포함률/기존 종양 clearance/거리 조건을 바꾸지 않고128개 모두의 유효성 mask와 이유를 기록한다.
유효 후보가0개인 환자는 명시적으로 실패시키며 환자나 donor를 제외하거나 임의로 바꾸지 않는다.
GNN 점수·가중치·전체 P+128U inference는 유지한다. 이미 완료한105개 score 파일은 원래 코드 SHA/수치 계산 AST/좌표/donor/모든P/checkpoint를 검증한 뒤 CP 생성부터 복구할 수 있다.
실제 nnU-Net 로더는 저장된 CP 유효성 mask의 최고 점수 index를 사용하고, 원래5회 RNG draw와 intensity jitter 순서를 보존한다.
원래 baseline Dataset730 fold0의105/26 split, ResEncM 128^3, CP 확률0.5,250 epoch 및 physical batch를 유지한다.
recipient별 donor 정책은 v2.3 고정 inner-train donor이므로 원래 Basic-CP의 donor 정책과 완전히 같다고 주장하지 않는다.
outer26 validation에는 CP를 적용하지 않고 prediction 입력은 CT뿐이다.
이26 case는 nnU-Net validation으로 사용되므로 최종 결과를 독립 test라고 부르지 않는다.
기존 nnU-Net normalization/planning 통계가105만으로 fit됐는지는 별도 미확인 사항이다.

가중치가 바뀌지 않고 GradScaler scale이 양수 범위에서 엄격히 감소한 overflow skip만 같은 batch/RNG/CP 집계로 다시 시도한다.

CP 원본 파일의 SHA/stat은 worker 생성 전에 한 번 검증하여 부모 로더에 보존한다. epoch별 worker는 이를 상속하며 매 접근의 파일 변경 검사는 유지한다.
이 방식은 epoch마다 전체 큰 배열을 반복해서 SHA 읽기하는 병목을 줄이며 RNG/CP 정책/epoch별 worker seed는 바꾸지 않는다.

GPU1 기존 native 준비의 안전한 연결
전체105 CP bank와131 preprocessing/GT 복사가 완료된 뒤 CUDA calibration에서 continue_training KeyError가 확인됐다.
설치된 nnU-Net의 실제 run_training CLI는 fresh 실행 시 plans의 메모리 사본에 continue_training=False를 넣지만,
직접 구성한 calibration clone이 이 필드를 전달하지 않았던 원인이다. 실제 constructor에서 이 값은 MetaLogger 계속 기록 여부에만 쓰인다.
별도 native calibration runtime은 원형 clone의 code object를 유지하며 정확한 plans 파일을 읽는 경로에서만 deep copy에 False를 전달한다.
기존 plans/private runtime/CP bank/복사 배열과8개 원형 CP source 파일을 덮어쓰지 않고 이전 실패 로그도 보존한다.
새 adapter/CLI/원형 private constructor 및 CLI의 AST/원형 함수/실제 trial과 calibration SHA를 별도 receipt로 검증한다.
clone의 실제 full128 loss/backward/update/CP 검증 후에만250 epoch native production을 시작한다.
이후 실제 부모 CP 로더가 완전한 native baseline_seg를 ndarray로만 인정하여 무손실 crop proxy를 거부하는 오류를 확인했다.
별도 v24_native_crop_runtime은 FrozenV23Loader에만 부모 paste method의 입력 인정 predicate1개를 메모리에서 재정의한다.
원형 ndarray 또는 실제 검증된 ROOT LosslessRawBankStore가 baseline_seg로 등록한 exact _CropArray만 인정한다.
전체 shape/int16 dtype/원형 baseline crop equality/CP support 및 감사 계산은 그대로 유지하며 전체 volume decode를 수행하지 않는다.
원형 NPY와 실제 무손실 codec의 padded crop 및 intensity jitter별 CT/seg/support/audit 값과 RNG 보존을 CPU DEBUG에서 비교한다.
실제 private trainer/parent/ROOT storage SHA와 method AST를 결속하며 기존8 CP source/private package/plans/기존 결과를 변경하지 않는다.
동일 protocol을 calibration 및 fresh native training subprocess에 적용한다. 원형 CLI argument tail과250 epoch 설정은 유지한다.
CPU 검사 통과와 실제 CUDA calibration 및250 epoch 전체 학습 완료는 각각 구분하여 실행 증거에 기록한다.
