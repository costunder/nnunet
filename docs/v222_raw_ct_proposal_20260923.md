# 원본 CT 기반 GNN 수정 명세 — 승인·구현된 원안

2026-09-23 사용자 답변 “이 전체 수정안으로 구현·검증 진행”으로 전체 원안을 승인받아 r3에 적용했다. 아래 내용은 당시 변경 명세를 보존한 것이다. 현재 구현·실측·제한은 [파이프라인](pipeline_v222.md)과 [검증 기록](v222_raw_ct_r3_verification_20260923.md)을 기준으로 한다.

## 확인한 문제

현재 inner-train84case의 적격 종양527개에서 중심부터 종양의 가장 먼 부분까지 거리의 중앙값은7.469852mm, 최대값은25.290656mm다. 모든 표본에 최대값+2mm=27.290656mm를 가려, 중앙값 기준 종양 가장 먼 부분보다19.820803mm 더 넓은 영역을 지운다. L0 노드 역시 이 반경 밖에만 있어 CT 가림만 제거해도 가까운 공간 문맥을 직접 그래프에 복원하지 못한다.

현재 학습 정답은 해당 중심에서의 종양 관측 여부이고, CP 추론 입력은 붙이기 전 recipient CT다. 이 관측 분류 softmax를128개 후보의 순위로 사용한다. 학습·추론에서 같은 전처리 함수를 쓴다는 사실만으로 배치 품질이 검증되지는 않는다. 모델이 실제로 어떤 단서를 사용하는지는 학습 후 개입 실험이 필요하다. 마스킹을 제거하면 자동으로 문제를 해결한다는 주장도 하지 않는다.

## 제안하는 원본 CT 기준선의 정확한 변경

| 항목 | 변경할 동작 |
| --- | --- |
| CNN 입력 | CT1채널을 기존 window/정규화로 입력. 중심 구를 상수로 치환하지 않음. GT 마스크·수작업 통계 채널 추가 없음 |
| L0 노드 | 기존 물리 outer radius55.290656mm, spacing2.5mm, edge radius6mm를 유지하고 내부27.290656mm 제외 조건 제거. 기존 외곽 노드를 모두 유지하며 내부 공간 격자 노드를 추가. GT를 따라 만든 종양 내부 전용 노드 종류는 없음 |
| L0 모델 | 기존 CNN12/24/32, GATv2 3층, hidden128, heads4 유지 |
| 비교 표본 | label1 위치 중 양성 anchor와 정확히 같은 좌표를 제외. 주변 종양 거리 제한 제거. case당128개 유지. 생물학적 음성으로 단정하지 않음 |
| 양성 표본 | 기존 적격 소형 종양 anchor 전부 유지. 원본 전체 종양 마스크는 바꾸지 않음 |
| L1/L2 | 기존 관측 관계와 환자별 군집 정렬을 유지. F를 기하적으로 불가능하다는 정답으로 바꾸지 않음 |
| 점수 의미 | 원본 CT 관측 분류에서 유도한 실험적 후보 순위. 배치 정답 확률이나 종양 발생 확률로 주장하지 않음 |
| CP | 기존 전체128개 후보를 같은 모델로 평가. 실제 붙이기는 기존 online 방식. CP0.8와seed42 유지 |
| 버전/결과 | 별도 format와 새 run을 사용. 기존 cache/checkpoint를 해시만 바꿔 재사용하지 않음 |

이 안은 큰 가림으로 정보를 지우는 문제를 제거하는 검증 가능한 기준선이다. 관측 분류와 배치 목적 사이의 간극이 해소됐다고 주장하지 않는다. 새로운 배치 품질 정답을 임의로 만들거나 기하 조건을 F의 정답으로 삼지 않는다.

전체 훈련 계약의 좌표로 읽기 전용 계산한 제안 topology는45,385nodes/2,383,482 directed edges(자기 연결 제외)다. 기존39,936nodes/2,040,356edges에서5,449개 내부 일반 노드가 추가된다. 이 수치는 모델에 적용된 결과가 아니라 변경 범위 확인이며 새 VRAM/처리량 검증을 대신하지 않는다.

## 실행 전후 검증 기준

1. 전체105 학습 case의 표본 생성이 패치 생성 전에 통과하는지 확인한다. 원본/분할/환자 group 배제 검사 유지.
2. 원본 중심 CT와 가까운 주변 CT를 각각 바꾸었을 때 입력과 CNN/L0 특징이 달라지는지 확인한다. GT 숫자만 바꿔도 동일 CT·중심의 모델 입력이 바뀌지 않아야 한다.
3. 새 topology가 기존 외곽 노드·엣지를 모두 포함하는지, 내부 격자가 실제 forward에 참여하는지 검사한다. 그래프 증가에 맞춰 실제 physical batch/VRAM/처리량을 다시 측정한다.
4. CNN/L0/L1/L2의 finite gradient와 optimizer 갱신, 모든 표본 방문, query/support 분리, inner-val/outer-val 격리를 확인한다.
5. 전체 GNN40epoch 후 inner-val에서 중심 appearance 교란과 주변 context 교란에 따른 점수 변화를 별도 진단한다. 이는 타당성 진단이며 ‘누수 없음’ 또는 ‘문맥만 학습’의 증명으로 쓰지 않는다.
6. 최종 효용은 동일 outer-val의 Basic CP80 대 GNN CP80 전체 nnU-Net250epoch 비교와 기존 소형 종양 평가로 판단한다. Donor/크기/crop 차이가 남으므로 GNN만의 효과라는 결론은 내리지 않는다. 좋은 위치의 별도 정답 데이터가 없는 한 위치 정확도를 임의로 보고하지 않는다.
