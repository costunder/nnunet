GPU5 입력 실행 최적화 적용용 수치 동일성 검사 (2026-10-10)

실제 적용 조건
본 작업 소유 GPU5 프로세스의 정확한 PID/create_time/argv/소유권을 확인한 후,
원형 STOP_AFTER_BATCH 저장 경계에서 PAUSED가 기록되고 CUDA가 비워진 경우에만 새 namespace를 준비한다.
prepare는 원형 checkpoint exact-copy inspector를 사용한다. latest/BEST/model/AdamW/
scheduler/scaler/RNG/shuffle state/history/curriculum/partial cursor와 원형 calibration을 그대로 승계한다.
현재 원형 source output은 experiment_gpu5_exact_recovery_1791620958225425000,
source code는 code_f22da14b6b91이며 f255 원형 scientific/runtime source와 동일한 복구 실행이다.
기존 결과나 원본 상태를 덮어쓰지 않고 신호로 강제 종료하지 않는다.

GPU5 native DEBUG probe와 gate
원형 full CNN+GAT 모델과 같은 exact checkpoint를 사용한다.
원형 maximum-cost 환자 liver_6/liver_129/liver_123/liver_69 네 명의 모든P+128U,
524개 후보,1048개 sampled views,17개 chunk32와4개 upper graph의 모든 실제 CPU tensor를 해시한다.
이 네 환자는 기존 physical batch calibration stress case이며 최종 학습 subset이 아니다.
baseline/optimized 모두 명시적인 DEBUG deterministic kernel policy를 사용한다.
production precision/kernel 설정은 그대로 유지하며 미지원 연산은 명시적인 오류로 처리한다.
매 실제981 named trainable parameter가 AdamW에 한 번씩 포함되는지 확인한다.
실제 forward/loss/backward 후981 gradients 모두 finite/connected이어야 한다.
실제 loaded model/AdamW/scaler/RNG가 source checkpoint의 저장 값과 같아야 한다.
optimizer update는0이며 검사 전후 persisted AdamW/scaler hash가 같아야 한다.
보존한 checkpoint의6개 numerical state와 전체진행상태를 probe 종료 후 다시 검증한다.
gate는 score524/loss/consistency와 모든981 gradients를 서버의 실제 tensor 파일에서 읽어
shape/dtype를 확인한 뒤 uint8 표현을 비교한다. signed zero 차이도 거부한다.
입력·output·loss·gradient·model·RNG·model contract·원형 checkpoint가 모두 같아야 train을 허용한다.
gate/probe 자체 source 파일을 원형 training wrapper의 private globals clone을 통해
기존 forward source guard에 추가한다. shared code object/global namespace와 원형학습코드는 변경하지 않는다.
검사한 optimized input adapter의 SHA가 현재 prepare/train에서 admitted된 source SHA와 같아야 한다.
optimized source chunk의 live chunk/entry/key/result/tree-visible bytes가 모두0이어야 적용한다.
