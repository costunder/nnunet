두 source의 역할을 구분한다. allocator는 실제 보존된 원형 파일에서 cold import한다.

선택된 실제 module SHA/contract를 세 probe의 모든 provider memory contract와 비교한다.
64GiB 한도와 strict failure0, source파일 witness도 요구한다.
