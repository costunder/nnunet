# v2.5 — 확정된 기반 설계

공식 STU-Net-S L0, 기존 L1/L2, 전체 관측 P를 쓰는 환자별 순위 loss를 유지한다.
문맥은 종양 footprint 밖 `0 < 거리 ≤ 10mm`, 간 경계로부터 `깊이 > 1mm`인 간 내부다.
학습·검증·CP에서 같은 정의를 사용한다.

네 커리큘럼은 고정된 128U 은행의 순서를 유지하며 A는 8개, B는 16개, C는 32개씩 누적한다.
D는 처음부터 128개를 사용한다. 40epoch 중 마지막 최소 8epoch는 전체 128U로 학습한다.
자세한 게이트와 데이터 계약은 [확정 설계](../../docs/v25_adaptive_context_curriculum_plan_20261011.txt)를 따른다.

이 폴더는 기반 설계의 입구다. 별도의 v2.5 전체 학습 완료 모델이 있다는 뜻이 아니다.
이 설계를 실행 코드로 반영하고 혈관 정보를 추가한 버전은 [v3.0](../v3.0/README.md)이다.

## 작업 완료 체크리스트

- [x] 서버 또는 원격 세션 종료 위험이 있는 명령을 사용하지 않았다.
- [x] 사용자 파일과 기존 결과를 파괴적으로 변경하지 않았다.
- [x] 모델 깊이와 너비를 편의상 축소하지 않았다.
- [x] 그래프와 데이터 규모를 편의상 축소하지 않았다.
- [x] 숨겨진 subset, cap, fast mode를 추가하지 않았다.
- [x] physical batch size와 병렬화 가능성은 기존 설계 계약을 유지했다.
- [x] GPU, CPU, RAM 활용 상태의 새 확인은 v3.0 검사에 구분하여 기록한다.
- [x] OOM 발생 시 모델 축소보다 메모리 및 병목 원인을 먼저 조사하는 계약을 유지했다.
- [x] 디버그 설정과 최종 설정을 분리했다.
- [x] dummy, placeholder, random fallback을 사용하지 않았다.
- [x] 핵심 모듈의 연결은 v3.0 구현 검사에서 확인한다. 이 문서는 설계 안내다.
- [x] 실제 실행 설정과 변경 사항을 명확하게 보고했다.
- [x] smoke test와 전체 학습 또는 전체 평가를 구분해서 보고했다.
