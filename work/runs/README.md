# 새 실험 결과 위치

새 실험은 `<버전>/<방법>/<실험명>/`으로 구분합니다. 예: `v1.9/listwise/seed42/`.

실험 폴더에는 README에 목적·비교 대상·GT·입력·완료 여부를 쓰고, 실행 설정과 commit은 메타데이터에 남깁니다. 이름에 긴 설명·전체 hash를 반복하지 않습니다. 같은 폴더에 다른 조건의 결과를 덮어쓰지 않습니다.

**이 안내가 기존 서버 실험을 새로 시작하거나 옮기지는 않습니다.** 현재 네 군의 실제 재개 경로는 [v1.8](../../versions/v1.8/README.md), [v1.9](../../versions/v1.9/README.md)의 독립 실험 안내를 따릅니다. 기존에 절대 경로·SHA로 연결된 로컬 실험도 원래 위치를 유지합니다.

## 작업 완료 체크리스트

이번 안내는 파일 관리에 한정합니다.

- [x] 서버 또는 원격 세션 종료 위험이 있는 명령을 사용하지 않았다.
- [x] 사용자 파일과 기존 결과를 파괴적으로 변경하지 않았다.
- [x] 모델 깊이와 너비를 편의상 축소하지 않았다.
- [x] 그래프와 데이터 규모를 편의상 축소하지 않았다.
- [x] 숨겨진 subset, cap, fast mode를 추가하지 않았다.
- [ ] physical batch size와 병렬화 가능성을 실제로 검토했다. (파일 관리에 해당 없음)
- [ ] GPU, CPU, RAM 활용 상태를 측정하거나 확인했다. (새 계산 실행 없음)
- [ ] OOM 발생 시 모델 축소보다 메모리 및 병목 원인을 먼저 조사했다. (해당 없음)
- [x] 디버그 설정과 최종 설정을 분리했다.
- [x] dummy, placeholder, random fallback을 사용하지 않았다.
- [ ] 핵심 모듈이 forward, loss, gradient와 optimizer에 연결되어 있다. (모델 변경·새 검증 없음)
- [x] 실제 실행 설정과 변경 사항을 명확하게 보고했다.
- [x] smoke test와 전체 학습 또는 전체 평가를 구분해서 보고했다.
